# Jaka Putra Tikalung — QA Manager Portfolio

Personal portfolio: 10+ years in software quality assurance, test automation (Playwright, Cypress, WebdriverIO, Appium) and AI-assisted QA.

Live site: https://jaka-putra-tikalung.github.io/Portofolio/

## Contents

- `index.html` — the site (styles and scripts inlined): Overview, Experience, Projects, Skills, Leadership, About
- `assets/shots/` — dashboard screenshots used in the Projects view (sample data, names replaced with placeholders)
- `cv/` — one-page CV (`CV_Jaka_Putra.pdf`), its HTML render and the editable template
- `og.png` — link preview image
- English / Bahasa Indonesia toggle, light / dark theme, mobile menu

## Run locally

Open `index.html` in a browser. No build step; the only external dependency is Google Fonts.

## Deploy

GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.
